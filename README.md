# Dario Ortega · Portfolio de modelo

Book digital de Dario Ortega, modelo de Blow Models y atleta de 400 m vallas. Incluye su ficha, campañas, editoriales, digitals y vídeos.

[Visitar la web](https://dnsue01.github.io/DarioOrtega/)

## En el repositorio

El sitio es estático. `index.html` contiene la página y las carpetas `fotos/`, `logos/` y `videos/` alojan sus recursos.
